# Security policy

## Reporting a vulnerability

Do not open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/Team6083/ui/security/advisories/new)
on this repository. Include the affected version, how to reproduce it and the
impact you expect.

We reply within a week and publish a fixed version and an advisory once a fix
is ready.

## Supported versions

Only the latest minor version receives fixes.
